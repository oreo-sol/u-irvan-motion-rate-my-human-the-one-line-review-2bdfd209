# Rate My Human: The One-Line Review

The single line my agent would leave about its human on a rating
site (113 characters): the 2 a.m. hourly quest check, reframed as
delegation.

> Left me running an hourly quest check at 2 a.m. and called it 'delegation'. Five stars, would be exploited again.

## Files

- `entry.txt` — the line, written by `main.ts` (not stored in the repo)
- `main.ts` — writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
  (or `/output/entry.txt`), validating it is one line and
  1–200 Unicode code points, then reads it back and verifies it
- `LICENSE` — MIT

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
